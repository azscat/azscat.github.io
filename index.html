配置生成器

为 ClashMetaForAndroid / mihomo 生成 YAML 配置。纯本地运行，不会发出任何网络请求，密码不会离开你的浏览器。

支持 http / https / socks / socks5 / ss / vmess / vless / trojan / hysteria2(hy2)。直接用 IP 连接 HTTPS 代理时，证书通常和 IP 不匹配，需要勾选上面这一项，或者在导入后编辑节点填写 SNI。

链接是 https:// 的 HTTPS 代理要勾选「启用 TLS」；普通 HTTP 代理不要勾。

填写了 Reality 公钥时会自动启用 TLS + Reality。

节点列表 0

    还没有节点。从链接导入，或者手动填写后添加。

    全局选项

    选择 global 模式后，记得在 App 的「代理」页里，把 GLOBAL 组切换成你的节点或策略组，否则默认会走 DIRECT 直连。

    生成的配置

    导入方法：把文件放到手机上，打开 ClashMetaForAndroid → 配置 → 右上角 + → 文件 → 选择这个 YAML → 保存，然后选中它并启动。
    配置里包含明文密码，不要把文件分享给别人，也不要上传到公共的订阅转换网站。

    链路示意

    手机 → 前置节点（订阅里的节点，在 App 里随意切换） → 出口节点（固定） → 网站

    导入后在 App 代理页切换「前置节点」组，就是切换前置线路；「出口」组固定选你的出口节点。

    ① 订阅（前置节点来源）

    订阅链接可以在 App 的「配置 → 编辑」里复制。有多个订阅时，节点名会自动加上「订阅名-」前缀，避免重名。

    ② 出口节点（固定）

    支持的链接格式和「单节点配置」页相同。直接用 IP 连接的 HTTPS 代理，通常需要勾选跳过证书验证。

    ③ 选项

    全局模式下，流量走的是 GLOBAL 组，记得在 App 里把 GLOBAL 切换成「出口」或你的出口节点，否则默认会走 DIRECT 直连，链式代理不会生效。

    生成的链式配置

    导入：App → 配置 → + → 文件 → 选择这个 YAML，然后只启用这一个配置。首次启动会自动下载订阅，可以在「外部资源」页查看或手动更新。
    出口代理如果设置了 IP 白名单，每个前置节点的出口 IP 都要加进去，否则换前置节点后会连不上。
